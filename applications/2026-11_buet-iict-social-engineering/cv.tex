\section{Security Research}
\cvProject
    {Hierarchical Network Intrusion Detection System for IIoT}
    {Python, scikit-learn, XGBoost, DCNv2, SHAP}
    {2026}
    {Undergraduate Thesis, PSTU}
    {
        \item Designed a dual-stream triage stage combining an XGBoost classifier over a 43-feature MQTT telemetry vector with parallel L3/L4 network heuristics, reaching 0.985 Macro-F1 at about 12.5 ms triage latency on a desktop baseline.
        \item Validated generalization with Leave-One-Attack-Out testing; recall stayed above 98\% on Brute Force and MITM but fell to 26.70\% on Malware, with the boundary mapped through SHAP analysis.
        \item Showed that random-split cross-validation inflated performance by up to 21 percentage points, and adopted strict chronological evaluation to remove the leakage.
    }
